# Recipe Website:

Introduction

Living on my own, I tend to struggle finding recipes that are delicious and also meet the needs of what I have at home. Most of the time I will just look up "Good chicken recipes" and just click one of the first options I see and a lot of the times, I do not have most of the ingredients listed. I then thought that it would be useful to have a website where I can put in the ingredients that I have at home using a filter and after clicking submit, a list of recipes tailored to those ingredients are displayed. 

Concept

After looking at some other websites that I use to find recipes, having a rating system for recipes can help users filter out the most popular dishes and ones that other users recommend. This would be a useful tool so that people who visit the website do not have to go through hundreds of recipes they will never use. Another tool provided to the user can be the option to look through either breakfast, brunch, lunch, dinner, or snack recipes. This would be part of a drop-down list from the navigation bar or a filter setting on the recipe page. Another important option that can be displayed for the user on the navigation bar is a community tab where users can discuss recipes and even add their own recipe to the website so that it can be displayed to the user. The user can add specific instructions on what to do in a step-by-step format as you would see on other websites. Lastly, I would also provide a randomizer option for those who my want to try something new and spontaneous. 

Conclusion

Although there are many other options I would provide for the user, this is a basic outline of some of the things that I want implement based on what I have seen. Through these given options to the user, there would be an extensive data component in which many recipes will have to be added and then distributed for the user to see. Any recommendations or ideas would be very helpful.
